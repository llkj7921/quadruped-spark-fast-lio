# Upstream FAST-LIO projects

This repository is an independently maintained derivative of:

- [MIT-SPARK/spark-fast-lio](https://github.com/MIT-SPARK/spark-fast-lio)
- [HKU-MARS/FAST_LIO](https://github.com/hku-mars/FAST_LIO)

The original project descriptions, datasets and standalone examples remain
available in their upstream repositories. This derivative retains the Git
history and GNU GPL v2 license; GitHub therefore lists upstream authors in the
contributor history.

The Mid-360 preprocessing, indoor/outdoor profiles, typed health reporting,
queue protection and recovery-controlled ikd-Tree updates in this repository
are project-specific changes and are not official upstream releases.
